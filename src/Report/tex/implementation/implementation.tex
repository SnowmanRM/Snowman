\chapter{IMPLEMENTATION}
\label{chap:implementation}

This chapter will focus on the technical implementation of \snowman. The first
sections cover programming languages, development tools and frameworks used
in this project. the most important modules including the GUI. Application
logging and the documentation and deployment of the software is covered at the
end of the chapter. Some sections within this chapter require a general
knowledge of the key concepts of \snort{} described in chapter
\ref{chap:concepts_of_snort}.
