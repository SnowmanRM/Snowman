\chapter{IMPLEMENTATION}
\label{chap:implementation}

This chapter focuses on the technical implementation of \snowman. The first
sections cover programming languages, development tools and frameworks used in
this project, followed by a description of the most important modules of the
server, including the GUI. Application logging and
deployment of the software is covered at the end of the chapter. Some sections
within this chapter require general knowledge of the key concepts of \snort{}
described in Chapter \ref{chap:concepts_of_snort}.
