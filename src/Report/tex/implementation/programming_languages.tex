\section{Programming languages}
Snowman is primarily written in Python 2.7. We discussed the possibility of
using the newer version of Python, 3.3, but found that version of Python to not have
matured enough yet. In addition, Django only had limited support for version 3.3
when we began the project. Our choice of Python was that of a practical nature.
All the members of the project team had experience with Python and found it
easier to work with than the C and C++ the school teaches. And since Snowman is
very database and object oriented, we felt that using C or C++ in this project
would be too time consuming. 

As for our web technologies, we've utilized HTML and CSS for the design and
Javascript for client side scripting.
