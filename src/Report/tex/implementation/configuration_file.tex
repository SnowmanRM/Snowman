There is a possibility that a rule will be moved from one rule set to another
by a source, for example the \ldots rules contain a ``deleted'' set which contains

create conflict during updates. In the server configuration file, users can
specify that rules should

\item always be moved when an update contains the rule within a different rule
set;
\item moved unless a user has previously moved the rule; or 
\item not moved at all.
\end{inparaenum}

the credentials of the sensor on which the client operates are stored, along
