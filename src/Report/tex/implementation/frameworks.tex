\section{Frameworks}
\label{sec:frameworks}
To prevent re-inventing the wheel to many times, we have decided to use several
frameworks to help us do generic tasks.

\subsection{Django}
To facilitate database transactions and the creation of the Web interface, this
project uses the \django{} \cite{django} framework.
\django{} is an extensive web-framework, designed to make the full process of
building web-based applications and their backends much more efficient and
simple. It takes care of the database ORM, which controls all the
database-transactions. \django{} is also providing a template-system for the
web-frontend, which make a clear line between the data and design of the
webpage.

\subsection{SQLAlchemy}
A database ORM would also be needed on the \snowman-client, but the rest of
django is not needed there. Because of that, SQLAlchemy is used on the client.

The SQLAlchemy framework is creating an abstraction over the database, and lets
us develop the code once, and still let the user decide which kind of database
to use on the client.

\subsection{jQuery}
When it comes to using JavaScript for client-side scripting, jQuery
\cite{jquery} is a good solution, as it provides a framework for common
JavaScript operations on the DOM\footnote{The webpage content or elements.} and
contains abstractions for a lot of browser-spesific code, which gives
programmers a nice and clean interface. It also makes AJAX-calls\footnote{AJAX
is web development technique that allows you to send asynchronous requests to a
web server.} a lot easier, requiring much less code compared to regular
JavaScript (example in Listing \ref{lst:ajax}).

\begin{javascript}[caption=AJAX call in jQuery and JavaScript.,label=lst:ajax]
// AJAX call in jQuery:
\$.get('/web/rules/');

// AJAX call in JavaScript:
function loadXMLDoc() {
    var xmlhttp;

    if (window.XMLHttpRequest) {
        // code for IE7+, Firefox, Chrome, Opera, Safari
        xmlhttp = new XMLHttpRequest();
    } else {
        // code for IE6, IE5
        xmlhttp = new ActiveXObject("Microsoft.XMLHTTP");
    }

    xmlhttp.onreadystatechange = function() {
        if (xmlhttp.readyState == 4 && xmlhttp.status == 200) {
            document.getElementById("myDiv").innerHTML = xmlhttp.responseText;
        }
    }

    xmlhttp.open("GET", "/web/rules/", true);
    xmlhttp.send();
}

\end{javascript}
\subsection{Bootstrap}
To facilitate the design and appearance of the web interface, this project uses
Bootstrap \cite{bootstrap}, which is a front-end framework derived from Twitter.
It provides a lot of ready made CSS and design elements that make a web page
responsive and typographically readable. Consider the example job of creating a
\htmlinline{<table>} element and spending hours setting up and tweaking the CSS
for the said table element, we could just add \htmlinline{<table class=`table
table-bordered`>} and get the table formatted nicely with colors and fonts that
are typographically matching.
