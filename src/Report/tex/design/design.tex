\chapter{DESIGN}

We decided to develop snowman as a distributed set-up. A central server should
be responsible for the user-interface and the sentral core-functions like
assigning rules to the sensors, get updates from the providers and simmilar.

Each sensor should in turn have installed a snowman-client, which is 
responsible for the communication with the central server, the generation of
the SNORT rule-files, and responding to the servers request for status.
