\section{Conclusion}
The project group has developed a system that works as intended and
solves the majority of the features requested of it. The group hopes that it can
be made useful in the battle to keep the internet safer, but only time will tell
if it will be adopted by the security community. 

The group has also found that it is quite difficult
to achieve performance in software when the expectations of functionality is high. We've also learned the importance of
conducting software performance testing before it is released, rather than
after. Because we conducted a performance test on our software, we were able to
implement optimizations that drastically improved the performance of one of our system modules.
