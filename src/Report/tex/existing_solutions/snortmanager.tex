\section{Snortmanager}
\snortmanager{} was created for a bachelor thesis written at \GUC{} in 2012,
where the main purpose of the software was to make rule management more
effective. This was done by creating a central server with a rule-database which
automatically downloads and updates rules from external sources, and creates
configuration files for sensors. \snortmanager{} has a high focus on producing
configuration files containing the necessary rules and settings for each sensor,
but does not automatically distribute the files to the sensors.
