\chapter*{Glossary}
This chapter contains an alphabetical list of technical terms used
throughout the report along with their definition.

\begin{description}
	\item[CLI] Command-line interface.
	\item[Daemon] A computer program that runs as a background process, usually
	without any user interaction.
	\item[DOM] Document object model.
	\item[HDD] Hard disk drive.
	\item[HTML] Hypertext markup language.
	\item[HTTP] Hypertext transfer protocol.
	\item[I/O] Input / Output, used to describe data flow to and from devices such
	as harddrives.
	\item[IDS] Intrusion detection system.
	\item[MD5] A cryptographic hash function producing a 128-bit hash value.
	\item[MVC] Model-view-controller.
	\item[Open Source Software] Software where the source code is publicly
	available and is licensed in such a way that the copyright holder grants the
	rights to study, alter and redistribute the software to anyone for any
	purpose \cite{OpenSourceSoftware}.
	\item[RAM] Random access memory.
	\item[RPC] Remote procedure call.
	\item[RPM] Rounds per minute.
	\item[SCP] Secure Copy - a file transfer protocol.
	\item[Sensor] A computer system wherein \snort{} and/or other security software
	is recording network traffic and produces alerts when malicious content is
	detected.
	\item[SSD] Solid state drive.
	\item[SSL] Secure sockets layer.
	\item[URL] Uniform resource locator.
	\item[XML] Extensible markup language.
\end{description}
